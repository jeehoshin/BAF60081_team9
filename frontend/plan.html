  • /ai/ask: 제목·장소·기간·가격 + 설명을 Gemini Embedding 2로 벡터화, Supabase pgvector 검색 Top-3만 [자료] 구획으로 프롬프트에 주입 (5주차). 유사도 임계값 미달 시 답변 보류
  • /ai/draft: 행사 메타데이터 + 말투(친근·간결·정중) 퓨샷 프롬프트. 손대지 않은 AI 칸 수를 승인 창에서 한 번 더 알림

  • 보안: API 키는 서버 .env에만, 모임톡·개인정보는 LLM에 보내지 않음
  • 확장 계획 · 날씨: 기상청 단기예보(공공데이터포털)를 에이전트 도구로 추가해 비 소식이면 실내 행사 우선
