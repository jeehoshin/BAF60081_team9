5UI/UX 설계 원칙 및 주요 화면 프로토타입 시연

2:55 – 5:10 · 시연 (평가 20%)

수업 자료(UIUX_용어집)의 AI 화면 설계(AI-UX) 12대 패턴과 비동기 상태(Loading·Empty·Error·Confirm)를 실제 공공 데이터가 연결된 React 프로토타입에 모두 구현했습니다.

🔎 1. AI 검색 (#search ↗)

사실 기반 신뢰도 표시(ai-confidence): 모델이 자체 출력한 confidence(92%)는 실제 정답 확률이 아니므로, 화면에는 "조건 N개 인식 · 근거 행사 M건"처럼 검증 가능한 사실로 표시하고 JSON 뷰어에서 스키마 원문을 대조합니다.

🧭 2. AI 동행 플래너 (#ask ↗)

인라인 인용(ai-citations) & 실행 단계(ai-trace): 문장마다 [1][2] 출처 번호를 눌러 근거 카드를 하이라이트하고, 실행 단계(Trace) 펼치기 및 다시 생성·복사·싫어요 사유 수집(ai-feedback)을 지원합니다.

✍️ 3. 모임 초안 (#draft ↗)

실행 전 사람 승인(ai-approval): 말투별 초안 생성 후 사용자가 수정한 칸은 직접 수정 배지로 즉시 바뀌며, 최종 확인 모달에서 손대지 않은 AI 초안 칸 수를 한 번 더 고지합니다.

⏳ 단계별 로딩 & 스켈레톤"문장 이해 → 행사 찾기 → 정리" 진행 단계와 카드형 스켈레톤 표시. 4초 초과 시 "그만 기다리고 직접 고르기" 탈출 버튼 제공
🔍 빈 결과 (Empty State)단순히 "0건"만 띄우지 않고, "무료 조건 빼기 9건"처럼 실제 데이터로 계산한 조건 완화 버튼을 제시해 다음 행동 안내
🔌 429 한도 초과 & 서버 오류입력한 질문을 지우지 않고 보존하며, 쉬운 원인 안내와 함께 "AI 없이 조건 직접 고르기(Fallback)"로 서비스 중단 방지
🔒 AI 고지 & 낮은 확신 확인입력창 하단에 외부 모델 전송 및 개인정보 입력 금지 고지(ai-disclosure), 모호한 질문은 먼저 조건 확인
🎬 발표 실시간 시연 시나리오 (2분 15초, 클릭 순서)
  1. [AI 검색 · 정상 및 칩 수정] 프로토타입 열기 → 예시 "이번 주말 서울 공연" 클릭 → 단계별 로딩 후 인식된 조건 칩·사실 기반 배지·AI 응답 JSON 보기 확인 → 칩의 ✕를 눌러 LLM 재호출 없이 결과가 즉시 바뀌는 것 시연
  2. [확신 낮음 & 미지원 조건] 예시 "아이랑 갈 만한 곳" 클릭 → 조건 확인 화면 + "‘아이랑’은 데이터에 없는 조건이라 반영하지 못했어요" 안내 확인
  3. [429 오류 & Fallback] 좌측 하단 🎬 시연 상태를 "요청 한도 초과 (429)"로 변경 후 검색 → 오류 복구 화면에서 "AI 없이 조건 직접 고르기"로 전환 후 다시 "정상"으로 복귀
  4. [RAG 동행 플래너 · 인라인 출처 & 답변 보류] 상단 탭 🧭 AI 동행 플래너 이동 → "이번 주말 종로구 공연 추천해줘" 클릭 → 답변 내 [1] 클릭해 하단 출처 카드 강조 & 실행 단계(Trace) 확인 → 이어서 "주식 투자는 어떻게 시작해?" 클릭해 "근거 없음 · 답변 보류" 시연
  5. [Human-in-the-Loop 모임 초안] 출처 카드의 "이 행사로 모임 만들기" 클릭 → 말투를 "정중하게"로 변경 → 모임 이름 수정 시 AI 초안 배지가 직접 수정으로 변하는 것 확인 → "확인하고 모임 만들기" 승인 모달 시연
